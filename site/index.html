One CLI for every ecosystem

xpm searches npm, PyPI, Packagist, crates.io and Maven Central at once, then installs with the right tool for your project. It uses one syntax, runs scripts from any manifest, and comes back in about a second.

go install github.com/crenspire/xpm/cmd/xpm@latest

Requires Go 1.22+ · other ways to install

$ xpm run test -- --watch

Stop remembering which tool does what

npm, pip, poetry, composer, cargo, mvn and go all spell the same idea differently. xpm translates for you and stays out of the way.

Search every registry

xpm which and xpm search query five registries in parallel and show where a name exists and its latest version.

One version syntax

name@version becomes ==, : or @, whatever the underlying tool expects.

Respects your lockfile

When you install, yarn.lock means yarn and poetry.lock means poetry, so xpm uses the tool your project already uses.

Run any project's scripts

xpm run build works with package.json, composer.json, pyproject.toml and Cargo, and passes args after -- through untouched.

Safe by default

Flag-like names are rejected, runtime downloads are checked against published SHA-256 sums, and archives can't write outside their folder.

Doctor

xpm doctor checks installed package managers, runtimes, lockfiles and project health in one report.

Fast, measured

Registries are queried in parallel with a hard 2.5 s deadline, payloads are tiny, and answers are cached on disk. Numbers below are from macOS arm64.
